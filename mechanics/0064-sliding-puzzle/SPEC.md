# Tile Shift (0064 — Sliding Puzzle)

## Rules
Restore tiles `1..8` on a `3 × 3` frame to row-major order `[1, 2, 3, 4, 5, 6, 7, 8, 0]` (`0` is the empty slot).
- Initial boards are generated by applying `44` legal slides from the solved frame using `state.rng`, guaranteeing every board is solvable and never starts solved.
- An action is the board index `0..8` of a tile orthogonally adjacent to the empty slot `0`.
- Sliding swaps that tile into the gap and increments `stepCount`.
- Game ends when solved (`solved = true`) or at `maxSteps = 220`.

## State
- `tiles`: array of 9 integers (`0..8`, permutation)
- `stepCount`: integer `0..220`
- `solved`: boolean
- `rng`: integer 32-bit PRNG state

## Actions
Sorted array of indices `0..8` orthogonally adjacent to `tiles.indexOf(0)` (empty `[]` when over).

## Score
`solved ? Math.max(20, 200 - stepCount * 2) : CorrectPositions * 10`
